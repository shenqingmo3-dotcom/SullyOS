# SullyOS iPhone 屏幕查看：快捷指令与真实测试

这条链路只在用户明确授权后工作：角色先在自主心跳里决定是否想查岗，VPS 随后发一封触发邮件；iPhone 个人自动化运行快捷指令，截取当前屏幕并上传；后端先做客观视觉识别，再载入该角色完整设定、聊天和记忆，把结果写成角色本人会说的一两句吐槽、评价、关心或追问。

成功看见后不会再次随机沉默。“不看、稍后看、保持沉默”属于调用工具之前的自主决定。识别失败时不会凭空编造反应。

## 一、VPS 设置

在 SullyOS 打开：设置 → 后端与自主活动 → 自主工具连接 → iPhone 屏幕查看。

填写：

- SMTP 主机：发件邮箱提供商的 SMTP 地址，例如 Gmail 为 `smtp.gmail.com`。
- 端口：SSL 通常为 `465`。
- 发件邮箱账号：真正用于发送触发邮件的邮箱。
- 邮箱授权码：邮箱提供商生成的应用专用密码，不是日常登录密码。不要在聊天里发送给任何人。
- iCloud 收件邮箱：当前 iPhone“邮件”App 能收到通知的 iCloud 邮箱。

先打开开关并保存。随后在“iPhone 快捷指令安装助手”中生成设备令牌。设备令牌相当于截图上传钥匙；更换令牌后，旧快捷指令立即失效。

域名审核期间，安装助手会自动使用当前 HTTPS 地址。以后切换到 `goldenbite.icu` 后，需要把快捷指令里的两个 URL 一起改为新域名，设备令牌不用因此更换。

## 二、建立快捷指令

快捷指令名称建议使用 `SullyOS 屏幕查看`。

### 1. 查询是否有待处理请求

1. 添加“URL”动作，填设置页显示的“待处理请求地址”。
2. 添加“获取 URL 内容”：方法选 GET。
3. 在标头中新增：
   - 键：`X-Sully-Device-Token`
   - 值：设置页生成的设备令牌
4. 从返回结果中“获取字典值” `data`。
5. 添加“如果”：仅当 `data` 有值时继续以下动作。
6. 从 `data` 中获取字典值 `requestId`，保留这个变量供上传使用。

### 2. 截图并压缩

1. 添加“拍摄屏幕快照”。
2. 添加“调整图像大小”，宽设为 `900`，高度自动。
3. 添加“转换图像”，格式选 JPEG，质量约 `55%`。
4. 添加“Base64 编码”，关闭换行（若当前 iOS 版本显示该选项）。

压缩是为了让上传稳定、减少流量和模型处理时间；不建议上传原始全分辨率 PNG。

### 3. 上传

1. 添加第二个“URL”动作，填设置页显示的“截图上传地址”。
2. 添加“获取 URL 内容”：方法选 POST，请求正文选 JSON。
3. 同样添加标头 `X-Sully-Device-Token`，值为设备令牌。
4. JSON 正文添加：

| 键 | 类型 | 值 |
|---|---|---|
| `requestId` | 文本 | 第一步取得的 `requestId` 变量 |
| `contentType` | 文本 | `image/jpeg` |
| `imageBase64` | 文本 | Base64 编码动作的结果 |

5. 结束“如果”。保存快捷指令。

## 三、建立邮件个人自动化

1. 快捷指令 → 自动化 → 新建个人自动化。
2. 选择“邮件”。
3. 发件人选择 VPS 设置中的 SMTP 发件邮箱。
4. 主题包含：`SullyOS 屏幕查看请求`。
5. 动作添加“运行快捷指令”，选择 `SullyOS 屏幕查看`。
6. 设为“立即运行”；如果系统显示“运行前询问”，将其关闭。

个人自动化只保存在当前设备。换手机后，要重新建立邮件自动化；快捷指令本体可以从旧手机分享为 iCloud 链接再导入。

## 四、真实端到端测试

1. 让 iPhone 保持已解锁，并停在一个容易识别、没有敏感信息的普通页面。
2. 在设置页“真实端到端测试”中选择角色并填写查岗目标。
3. 点“发送真实测试邮件并等待 iPhone”。
4. 正常状态依次为：等待 iPhone 回传 → 截图已上传 → 完成。
5. 设置页会显示客观识别文本和角色最终发出的反应；聊天页会出现手机活动卡片和角色消息，Web Push 已开启时还会收到系统通知。

测试请求十分钟后自动过期。若停在“等待 iPhone 回传”，优先检查邮件是否到达、自动化是否设为立即运行，以及发件人/主题筛选是否完全一致。若显示“失败”，按页面展示的识别或模型错误排查。

## 五、边界与隐私

- iPhone 必须处于可截图状态；锁屏时快捷指令不能替你解锁。
- 受 DRM 保护的视频、部分银行或安全 App 可能只产生黑屏或空白图。
- 截图会保存在自己的 VPS 数据库中，并显示为活动记录；设备令牌只允许查询待处理请求和上传截图，不能管理 SullyOS 其他数据。
- 不要把邮箱授权码、设备令牌或后端访问令牌发在聊天、截图或公开教程中。
- 不建议把该自动化改成固定频率后台偷拍；它只响应角色已经作出的单次查岗请求，每个请求十分钟后失效。
